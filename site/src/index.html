Your agent forgets at /clear. kb does not.

kb keeps what Claude Code learns as plain markdown notes, gives every new session a small index of them, and loads a note when it applies. This page is one session with it.

Install the pluginRead the sessionFree and open source (MIT)

Where kb fits

kb is a plugin for Claude Code, and it is pre-release. Claude Code already has two places for memory. kb is the third, for what the agent learns.

CLAUDE.mdHolds the rules that you state. Every session loads all of it.
auto memoryHolds what Claude Code saves by itself. It loads all of it at every start.
kbKeeps what the agent learns. A session gets a small index, and a note loads only when it applies.

    kb contextA note whose file or symbol is gone or changed is flagged at session start, before I act on it.
    /kb:auditChanged notes that no session checked, and notes with no activity and no check in 90 days, go up for review. Rules move into CLAUDE.md.

    kb syncGive the store a remote. Every machine shares it.

### stripe-signature-check-needs-the-raw-body [gotcha] Stripe signature check needs the raw body
anchor on api/webhooks.ts#verifySignature
changed since the last check: api/webhooks.ts#verifySignature
Check the signature before any JSON parse. A parsed body fails the check, and the error names no cause.

A note with "changed since the last check" is on a file that changed after the note was last checked. Read the code before you act on such a note. If the note still holds, run `kb verify <id>`. If it does not, update it with `kb add`. If you cannot fix it now, run `kb verdict wrong <id>`.

  19. >
    how do I install it?
  20. ●

    You need Claude Code 2.1.275 or later, Bun 1.x and git, on macOS or Linux. There is no build step and no dependency.

    installtwo steps
    # 1. in Claude Code
    /plugin install kb --marketplace jrnxf/plugins
    # 2. merge into ~/.claude/settings.json
    {
  "autoMemoryEnabled": false,
  "permissions": {
    "allow": [
      "Bash(kb help)",
      "Bash(kb show *)",
      "Bash(kb search *)",
      "Bash(kb add *)"
    ]
  }
}

    Add these keys to the file you have. Do not replace it. The settings turn off auto memory, since kb replaces it, and let me read and save notes with no question.
